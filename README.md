# The Pandel — App Releases

Official APK downloads for **The Pandel**, the Kolkata Durga Puja companion app.

Grab the latest build from the [Releases](../../releases/latest) page.

- Most phones: `app-arm64-v8a-release.apk`
- Older/budget phones: `app-armeabi-v7a-release.apk`
- Any Android device: `app-universal-release.apk`

Website: https://thepandel.vercel.app
